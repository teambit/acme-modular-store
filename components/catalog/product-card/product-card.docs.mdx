`ProductCard` shows one catalog `Product`: its name, description, price, a stock badge ("In stock", "Only N left" or "Out of stock") and its rating. The "Add to cart" button is disabled while the product is out of stock, and is labelled with the product name so screen readers can tell cards apart.

## Show a product

```tsx
import { ProductCard } from '@acme-modular/store.catalog.product-card';

<ProductCard product={product} />
```

## Add to the cart

```tsx
import { ProductCard } from '@acme-modular/store.catalog.product-card';
import { useCart } from '@acme-modular/store.cart.use-cart';

const { add } = useCart();

<ProductCard product={product} onAddToCart={(product) => add(product)} />
```

## From the demo catalog

import { mockProducts } from '@acme-modular/platform.entities.product';
