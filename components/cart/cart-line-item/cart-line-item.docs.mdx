`CartLineItem` renders a single `CartLine` with a quantity stepper and a remove action. It is controlled: it reports the new quantity through `onQuantityChange` and never steps below 1, so removing a line is always an explicit `onRemove`.

## With the cart hook

```tsx
import { CartLineItem } from '@acme-modular/store.cart.cart-line-item';
import { useCart } from '@acme-modular/store.cart.use-cart';

const { lines, setQuantity, remove } = useCart();

{lines.map((line) => (
  <CartLineItem
    key={line.productId}
    line={line}
    onQuantityChange={(quantity) => setQuantity(line.productId, quantity)}
    onRemove={() => remove(line.productId)}
  />
))}
```
